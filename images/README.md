## Image Specifications

### Unit Images
- **Size**: 800x600px minimum
- **Format**: JPG or PNG
- **Style**: Group photos showing unit activities

### Team Images
- **Size**: 400x400px (square) recommended
- **Format**: JPG or PNG
- **Style**: Individual portrait photos, consistent style

### Gallery Images
- **Size**: 1200x800px minimum
- **Format**: JPG
- **Style**: Event and activity photos

## Tips

1. **Optimize images**: Compress images to reduce file size while maintaining quality
2. **Consistent styling**: Try to maintain a consistent look across similar image types
3. **Alt text**: The HTML includes alt text for accessibility
4. **Backup**: Keep original high-resolution images backed up separately

## Temporary Placeholders

If you don't have images ready yet, the website will show placeholder text. You can:
1. Use colored divs as temporary placeholders
2. Use free stock photos from Unsplash or Pexels
3. Use gradient backgrounds as placeholders

The CSS includes basic placeholder styling for missing images.
